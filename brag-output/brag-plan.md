# BRAG Plan — Employee Compensation & Workforce Analysis

## Invocation
`/brag --tone cinematic` (cinematic, landscape, no voice).

## 9-question rubric

1. **What is the app?**
   An end-to-end HR analytics project: a Python pipeline cleans a 107-row × 20-column workforce dataset, engineers five new fields, runs EDA, loads MySQL where 20 SQL business questions are answered, and feeds a Power BI dashboard and written report.

2. **Most impressive claim.**
   One 107-employee dataset carried through a full analyst workflow — Python → SQL → Power BI — answering 20 real compensation questions, from payroll by country to pay position inside job ranges.

3. **Visual hook.**
   A workforce table resolving into a living pipeline — raw rows becoming answers and a dashboard.

4. **What should be shown from the actual project?**
   The end-to-end pipeline (Dataset → Python → Cleaning → Feature Engineering → EDA → MySQL → SQL Analysis → Power BI → Report) and the five engineered features that power the analysis.

5. **Shortest satisfying video.**
   20 seconds. Hook → reveal → pipeline → SQL hero → feature cards → outro.

6. **Tone.**
   Preset: `cinematic`. Direction: "workforce analytics — payroll with a pulse."

7. **Audio.**
   Steady cinematic bed (`vol-12`), restrained impacts and ticks. Audio-reactive: subtle; cards and stat glow breathe with RMS. No waveform visuals.

8. **Share caption.** See `share-copy.txt`.

9. **User flow worth showing.**
   Raw workforce CSV → Python clean + engineer → SQL analysis → Power BI dashboard → executive report.

## Angle

Most people see payroll as a cost column. This project treats it as a dataset full of human patterns — and walks it all the way from a messy CSV to a dashboard a manager can act on. Cinematic scale, confident, precise claims only.

Pattern: Hook (0–3.5s) → Reveal (3.5–7.0s) → Highlights (7.0–17.4s) → Outro (17.4–20.5s).
